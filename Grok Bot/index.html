TechCrunch 独家获悉，帕洛阿尔托人工智能初创公司 Elorian 在推出产品之前以 3 亿美元的估值筹集了 5500 万美元的种子轮资金，周五发布了其第一个模型。 该模型 Glimpse 正在作为具有 API 访问权限的研究预览版推出，并且聊天界面仅限候补名单，因此目前它只是一个结果表和一篇论文。 论文？ 今天的人工智能模型，尽管拥有丰富的语言和代码技能，但仍然无法真正看到东西。 大多数多模态模型查看图像一次，将其转换为标记，然后用文本对其进行推理 - 就像凭记忆描述照片一样。 一瞥不断回到源头。 在推理过程中，它可以裁剪到一个区域，从视频中提取特定帧，或者运行代码来测量或比较它所看到的内容，埃洛里安将这种机制称为“视觉暂存空间”。 想象一下，有人捏住手机照片进行放大，以仔细检查他们认为看到的内容。 对于前谷歌 DeepMind 研究员兼 Elorian 首席执行官 Andrew Dai 来说，人工智能仍然无法真正看到的最明显迹象之一出现在比赛之夜。 去年，他拍摄了一场刚刚和朋友玩完的棋盘游戏，并询问一位前沿模特谁获胜了。 它不能说。 他告诉 TechCrunch，“每种棋盘游戏都有自己的视觉语言、图像和符号”。 “对于成年人来说，用最少的文本很容易理解发生了什么，但这些模型无法凭直觉理解这些符号的含义。” “人类可以查看没有文字的宜家图表并组装宜家家具，对吧？为什么人工智能模型不能？” 他说。 这种方法并不是全新的——OpenAI 在 2025 年为其 o 系列模型添加了推理过程中的裁剪和缩放功能——但 Elorian 的宣传是，它围绕它构建了整个模型，而且成本低廉。 该公司表示，一个小团队在几百个 GPU 上训练了 Glimpse，该模型比其基准测试的前沿系统要小得多。 Glimpse 的成本为每百万代币 0.60 美元，每百万代币输出 3 美元——比 Sonnet 和 Sol 等中级模型便宜，但比 Haiku 和 Luna 等轻量级模型贵。 但根据 Elorian 的评估，Glimpse 在科学图表推理和短视频字幕方面的表现甚至优于 GPT-6 Astra，在其他视觉推理任务上也有竞争性的结果。 六个月前，Elorian 在由 Striker Venture Partners、Menlo Ventures 和 Altimeter Capital 共同领投的一轮融资中脱颖而出，Nvidia 和谷歌首席科学家 Jeff Dean 也参与其中。

最初的目标是拥有大量视频的公司：机器人公司、科学实验室、媒体和创意公司。 从长远来看，埃洛里安希望从看到转向行动。 这意味着建立一个场景模型，用它来选择一个动作，包括直接控制机器人。 戴说，明年，该公司的目标是建立“世界上最好的视觉推理模型”，该模型在每项视觉推理测试中都处于领先地位。
