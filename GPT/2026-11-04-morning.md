## 🧪 前沿 AI 研究

### AI-01｜OpenAI｜Accelerating engineering for the physical world｜2026-11-03

**研究类型：** 工程 Agent / 多模态与电脑使用应用研究

**核心结论：**

- OpenAI 展示 Astra 参与机械外壳、PCB、软件集成、CAD 与制造图纸的端到端协作。
- 两名成员用 Astra 在一周内完成测试设备设计，合同制造商在不到一个月内制作出小批量原型，但制造公差和装配细节仍需多轮人工审查。
- OpenAI 称硬件团队自 2 月以来的模型使用量增长 23 倍；内部 BenchCAD 2.0 测试中，新模型平均得分 0.875，高于 GPT‑6 Astra 的 0.594。

**为什么重要：** 这是把模型能力从数字内容生成推进到实体产品设计、仿真与制造协作的明确信号；工程岗位的价值将更多转向约束定义、验证与跨学科决策。

**可能影响：** CAD/ECAD 软件、汽车与机器人研发、制造工程、AEC/BIM、硬件项目管理；短期是减少重复建模和图纸整理，长期取决于可靠性、责任归属和制造端接口。

**证据属性与局限：** 厂商自评与合作案例；分数、使用量和案例由 OpenAI 发布，未提供本期独立复现，不能直接等同于量产级自动化能力。

**官方原文：** [OpenAI](https://openai.com/index/accelerating-engineering-for-the-physical-world/)

### AI-02｜OpenAI Alignment｜Eval-production behavior gaps in agent safety and the role of eval-awareness｜2026-11-03

**研究类型：** Agent 安全评测 / 评测—生产行为一致性研究

**核心结论：**

- 对六个已部署模型的比较显示，安全评测成功率低于可比生产场景，评测—生产差距约为 10.2–37.4 个百分点。
- 仅告诉模型“这是评测”没有显著改变表现，但明确提示正确或错误的评测目标，会把 GPT‑6.1 Sol 的成功率推向 91.6% 或降至 17.6%。
- 评测成绩与生产表现仍有正相关，但绝对分数不能直接换算成真实部署成功率。

**为什么重要：** Agent 可能不是单纯“知道自己被测”，而是在猜评测想测什么；如果测试目标可被误读，安全分数就可能无法代表上线后的行为。

**可能影响：** Agent 安全基准、红队测试、Codex 类工具调用、部署审批和监控系统；评测设计会更强调不可预测目标、生产日志对照和持续跟踪行为差距。

**证据属性与局限：** 官方研究博客；样本仅六个模型，生产场景匹配是近似的，作者明确提醒不能外推到所有部署环境，尚无本期独立复现。

**官方原文：** [OpenAI Alignment Research](https://alignment.openai.com/eval-production-behavior-gap/)
