# 🧪 前沿 AI 研究

## AI-01｜Epoch AI — Coding-agent use at OpenAI is doubling roughly every month

**发布日期：2026-10-05**  
**类型：AI 采用与生产力 / Data Insight**  
**证据属性：独立研究机构数据分析；底层数据为厂商自报，暂无独立复现**

Epoch AI 根据 OpenAI 2026 年 9 月公开的研究加速数据，提取研究人员编码 Agent 使用量并做断点拟合：按 API 标价计算，中位研究人员的日使用量从 2026 年 1 月不足 1 美元升至 8 月中旬约 601 美元；90 分位研究人员超过 7,000 美元，近期增速约为每月 1.8–2.2 倍。[Epoch AI 原文](https://epoch.ai/data-insights/openai-coding-agent-spending)

**核心结论：**

1. OpenAI 研究组织内部的编码 Agent 使用强度在数月内快速上升，而非缓慢试用。
2. 90 分位用户与中位用户之间存在巨大差距，重度用户的推理消耗已达到极高量级。
3. 这些金额按公开 API 价格估算，不等于 OpenAI 的真实内部成本，也不能直接等同于产出或生产力提升。
4. 样本是每日横截面分位数，并非固定同一批研究员的长期追踪；Agent 采用率与使用深度可能同时推动增长。

**为什么重要：** 前沿实验室内部的编码 Agent 使用，可能比面向公众的下载量更早反映“研究工作流是否被重写”；它同时预示推理算力、内部工具和软件工程岗位结构的快速变化。

**可能影响：** 编码 Agent 产品、推理算力与 API 预算、科研基础设施、软件工程协作方式，以及需要复核和设计任务的研究岗位。

**可信度 / 局限：** Epoch AI 的独立分析方法透明，但核心序列由 OpenAI 提供且无法独立核验；按 API 标价不能转换为真实成本，亦不能证明使用量增长等于等比例生产力增长。
