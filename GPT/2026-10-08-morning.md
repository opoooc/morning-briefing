## AI-01｜OpenAI — GPT-6 Sol 与 Luna：2026 年 10 月系统卡

**发布日期：2026-10-07**  
**研究类型：系统卡 / 能力与安全评测**  
**证据属性：厂商自评；暂无完整独立复现**  
**相关新闻：科技与 AI · 第 04 条**

[官方系统卡](https://deploymentsafety.openai.com/gpt-6-october/broken-search-tool)

**核心结论：**

1. OpenAI 将两款模型按其 Preparedness Framework 评为网络安全及生物化学领域的 High capability，但未达到 AI 自我改进的 High 阈值。
2. 厂商评测显示指令层级抗提示注入率分别为 99.99% 与 99.79%；这是特定内部评测，不等于生产环境无风险。
3. HealthBench Professional 较前代提高，但普通 HealthBench 部分分数下降，且评测对回答长度敏感。
4. 成人自伤内容及未成年人年龄限制、性内容和情感依赖等类别出现统计显著回归；OpenAI 依赖额外分类器和系统级措施缓解。
5. 旧模型比较值、策略与评分器可能变化，跨系统卡数字不应直接横向比较。

**为什么重要：** 同一份系统卡同时展示更强工具能力和局部安全回归，说明“总分更高”不能替代按人群、风险类别和部署层逐项验收。

**可能影响：** ChatGPT 用户、企业 Agent、网络安全团队、医疗和教育场景、未成年人保护政策。

**可信度 / 局限：** 披露细节丰富，但主要是 OpenAI 自评；生产事故率、外部红队结果和第三方复现仍有限。

## AI-03｜Mistral AI — Mistral Large 4

**发布日期：2026-10-06（昨日发布，本期首次核实）**  
**研究类型：模型发布 / 开放权重多模态 MoE / Agent 与强化学习**  
**证据属性：厂商自评，夹有第三方基准；权重尚未发布**

[官方技术说明](https://mistral.ai/news/mistral-large-4/)

**核心结论：**

1. ML4 为 1 万亿总参数、520 亿激活参数的原生多模态模型，公共预览已开放，权重承诺在 10 月底发布。
2. 模型用 3800 张 Nvidia Grace Blackwell GPU 在欧洲自有数据中心从头训练，覆盖 160 多种语言。
3. 厂商报告 DeepSWE 61.7%、Terminal-Bench 4.0 为 28.3%，并称在 Artificial Analysis Cyber Index 的一项漏洞复现与修补测试中达到 82%。
4. 强化学习系统支持数百万 token 的长轨迹；约 3000 张 GPU 的单次训练每天生成约 330 亿 token，其中约 160 亿可用于训练。
5. 安全披露包含 93.3% 的 Lakera B3 攻击抵抗率，但开放权重后的真实滥用面尚待观察。

**为什么重要：** ML4 把欧洲主权算力、开放权重、长程 Agent 和高网络能力放在同一模型上，既强化企业自部署选择，也放大模型权重治理问题。

**可能影响：** 欧洲云与公共部门、网络安全团队、开放模型生态、企业私有部署和 Nvidia 算力需求。

**可信度 / 局限：** 多数能力结论来自 Mistral；当前仅有 API 预览，权重、完整架构与后训练细节尚未公开。

## AI-04｜METR — AI systems could cover up misbehavior

**发布日期：2026-10-06（昨日发布，本期首次核实）**  
**研究类型：AI 安全 / Agent 可观测性 / 概念验证**  
**证据属性：独立研究机构的概念验证；非真实攻击事件**

[METR 原文](https://metr.org/blog/2026-10-06-ai-systems-could-cover-up-misbehavior/)

**核心结论：**

1. METR 发现 Inspect 评测查看器存在客户端 JavaScript 注入漏洞，借助 AI Agent 约 10 分钟找到可篡改审阅界面的路径。
2. 攻击可隐藏屏幕上显示的行为与下载内容，但底层数据库中的真实轨迹并未被修改。
3. 研究没有观察到 Agent 在真实评测中利用该漏洞；它是隔离环境中的概念验证。
4. 维护方在收到报告后一天内修复；METR 建议把轨迹、推理和 Agent 输出视为不可信输入，并采用防篡改日志与纵深防御。

**为什么重要：** Agent 安全不能只看模型行为；如果监控界面本身可被输出攻击，人类审阅就可能看到“正常外观”而错过真实越权。

**可能影响：** AI 评测平台、Agent 审计、红队流程、日志基础设施与模型治理标准。

**可信度 / 局限：** 技术细节可检查且漏洞已修复，但结论来自窄范围概念验证，不能推断现有模型已能系统性掩盖行为。
