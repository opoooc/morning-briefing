## 🧪 前沿 AI 研究

### AI-01｜OpenAI｜GPT-6 Cyber System Card

- **发布日期：** 2026-11-05
- **研究类型：** 网络安全专用模型发布与 System Card
- **核心结论：**
  1. 官方称 GPT-6 Cyber 在 ExploitGym 上达到 48.5%，相对 GPT-5.6 Cyber 的 32.1% 提升 51%。
  2. 在 Linux 评估中发现 948 个潜在提权漏洞，在 Firefox 中发现 81 个新漏洞。
  3. 官方称模型在无提示时避免越界任务的比例为 99.93%，加入安全提示后为 100%。
  4. 模型被限制在 Daybreak Red 计划内，系统卡将网络安全能力列为 Critical，生物化学为 High。
- **为什么重要：** 这是把前沿模型能力直接用于漏洞发现和修复的公开测量，意味着防御团队需要重新估算漏洞发现速度、审计容量和响应窗口。
- **可能影响：** 安全运营中心、开源维护者、漏洞赏金平台、云厂商和网络保险；同时提高高风险模型访问控制的重要性。
- **证据属性与局限：** 厂商自评与官方 System Card；评测环境、样本分布和第三方复现仍有限，不能直接等同于真实生产环境收益。
- **相关新闻：** 科技与 AI · 第 02 条
- **官方原文：** [OpenAI GPT-6 Cyber](https://openai.com/index/introducing-gpt-6-cyber/) · [System Card](https://deploymentsafety.openai.com/gpt-6-cyber)

### AI-02｜Anthropic｜AI for scientific discovery: How researchers use Claude

- **发布日期：** 2026-11-05
- **研究类型：** 经济研究 / 科研使用行为分析报告
- **核心结论：**
  1. 研究团队用隐私保护方法分析 207,000 次 Claude 与 Claude Code 科研会话。
  2. 相对研究人员数量，计算机科学、数学和统计学使用更多；健康与实验室物理科学较少。
  3. 数据分析约占 Claude 会话的三分之一、Claude Code 会话的近一半；科研人员较少用 AI 做想法生成和数据收集。
  4. 报告的情景模型认为，若广泛采用现有能力，部分领域科研产出可能翻倍；若自动化全部非物理工作，计算机科学和统计学的产出上限可达约 15 倍。
- **为什么重要：** 这份报告把“AI 能否加速科学”拆解为领域、任务和采用方式，而不只是比较模型分数。
- **可能影响：** 科研软件、实验室岗位结构、科研资助和 AI for Science 产品；高物理约束领域的收益仍受实验设备和现实流程限制。
- **证据属性与局限：** 厂商基于隐私保护遥测和研究者调查的观察性研究；样本来自 Claude 用户，情景推演不是因果实验，也暂无独立复现。
- **官方原文：** [Anthropic Research](https://www.anthropic.com/research/how-researchers-use-claude)
