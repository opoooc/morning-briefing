## 🧪 前沿 AI 研究

### AI-01｜Meta — Muse Wonder：面向长任务 Agent 的前沿模型系列

**发布日期：2026-10-12**  
**研究类型：模型发布 / Model Card / Agent 与计算机操作**  
**证据属性：厂商自评；有限独立评测；完整安全报告尚未发布**  
**相关新闻：科技与 AI · 第 01 条**

Meta 发布 Muse Wonder 与 Muse Wonder Full，模型采用闭源 API/订阅方式提供，均支持约 100 万 Token 上下文，重点覆盖长期编程任务、工具调用、计算机操作、记忆和任务恢复。

**核心结论：**

1. Meta 称两款模型在增加测试时计算后，对分布外任务均能继续提升；更强的基础模型使 Wonder Full 的泛化增益高于此前 Muse Spark 趋势。
2. “Active Memory”用于跨对话保留相关信息，“Active Focus”用于在长任务中更换策略、从错误中恢复并在关键动作前确认。
3. Meta 自评显示 Wonder Full 在部分法律、金融、自动化及长周期编程基准领先，但其自建综合指标和厂商测试不能直接视为独立验证。
4. 独立汇总页面记录 Muse Wonder 在 Artificial Analysis Intelligence Index 得分 52、并列第 7；多项 Meta 展示的 Agent 基准尚没有相应独立公开成绩，Wonder Full 也未开放普通 API。
5. Meta 称 Wonder 具有其迄今最强的 CBRN、网络滥用及隐私保护措施，但完整安全评估报告仍“稍后发布”。

**为什么重要：** Meta 再次推出可与主流闭源模型竞争的高价前沿 API，并将重点放在长时间 Agent 和个人上下文。如果能力成立，模型竞争会从单轮推理转向任务持续性、计算机操作和记忆安全。

**可能影响：** OpenAI、Anthropic、Google 的 Agent 产品与定价；编程助手、法律和金融工作流；个人助理、浏览器自动化及企业安全审计岗位。

**可信度 / 局限：** 性能主体来自 Meta 自评；Artificial Analysis 仅提供部分通用能力信号，不能验证全部 Agent 宣称。模型权重未开放，Wonder Full 的可访问范围有限，完整安全报告尚未公开。
